# GlowCare 🌿

GlowCare is a web-based skin and hair care system that recommends natural
care routines based on the user's skin type (oily, dry, normal, combination,
sensitive) and hair type and concerns.

## Features
- Skin and hair type selection (or a short questionnaire to find your type)
- Natural morning and night routine recommendations
- Allergy filter and safety precautions
- Daily reminders with done / skip / snooze
- Daily log, feedback ratings and progress dashboard
- AI features: skin photo analysis, smart recommendations that improve
  with feedback, and a skin/hair care chatbot

## Tech Stack
Python, FastAPI, MySQL, SQLAlchemy, HTML/CSS/JS, Chart.js, scikit-learn / PyTorch

## Disclaimer
GlowCare gives general wellness suggestions only. It is not a medical
diagnosis tool. For serious skin or hair problems, please consult a
dermatologist.
